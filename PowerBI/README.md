# Power BI Dashboard

This folder contains the final interactive Power BI dashboard developed for the Bike Sales Analysis project.

## Dashboard Features

- Revenue Performance Analysis
- Net Profit Performance Analysis
- Revenue and Net Profit Overview
- Financial Insights
- Business Recommendations

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization

## Dashboard File

`BIKE SALE ANALYSIS FINAL VISUALIZATION.pbix`

The Power BI file can be downloaded and opened using Microsoft Power BI Desktop.
