# Europe Bike Sales Analysis – Project Overview

## 1. Project Overview

This project analyses the Europe Bike Store Sales dataset to evaluate business performance across revenue, net profit, product categories, customer purchasing behaviour, and geographical sales distribution.

Microsoft Excel was used for data cleaning, data preparation, and preliminary analysis, while Power BI was used to develop an interactive dashboard, calculate key performance indicators (KPIs), and generate business insights.

The objective was to transform raw bike sales data into meaningful information that supports business decision-making, identifies sales trends, and highlights opportunities for improving revenue and profitability.

## 2. Dataset Source

The dataset used for this project was obtained from Kaggle.

- **Dataset Name:** Europe Bike Store Sales
- **Source:** Kaggle
- **Dataset Provider:** PrepInsta Prime
- **Dataset Link:** [Europe Bike Store Sales – Kaggle](https://www.kaggle.com/datasets/prepinstaprime/europe-bike-store-sales)

The dataset contains bike sales transaction records used to analyse financial performance, product performance, customer purchasing patterns, and geographical sales distribution.

## 3. Project Objectives

The main objectives of this project were to:

- Evaluate overall revenue and net profit performance.
- Analyse monthly revenue and profit trends.
- Identify high-performing and low-performing product categories.
- Examine customer purchasing patterns and demographics.
- Evaluate sales performance across different countries.
- Identify business opportunities to improve revenue and profitability.
- Develop an interactive Power BI dashboard for business reporting.

## 5. Project Workflow

The project followed these stages:

1. **Data Collection:** Obtained the Europe Bike Store Sales dataset from Kaggle.
2. **Data Cleaning:** Used Microsoft Excel to inspect, clean, and prepare the dataset.
3. **Data Preparation:** Organised the data for analysis and reporting.
4. **Data Analysis:** Examined revenue, net profit, product performance, customer trends, and geographical performance.
5. **Dashboard Development:** Created an interactive Power BI dashboard with relevant KPIs and visualisations.
6. **Business Insights:** Identified key findings and developed recommendations based on the analysis.
